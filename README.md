Leonida Ledger — an offline web guide and tracker for all 55 PlayStation 5 trophies of Grand Theft Auto VI: the official list with a cited guide for every trophy, a checklist saved in the browser with export and import, filters by kind, a spoiler setting that hides story trophies until earned, a roadmap to the platinum, and the one potentially missable trophy flagged. Static files under `app/` — open `app/index.html` in a desktop browser with the network off and it just works.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080.
